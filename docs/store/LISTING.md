## 詳しい説明（4000文字以内）

```
フリックIMEは、通信を一切行わない日本語フリック入力キーボードです。

■ 主な特徴

・ケータイ配列のフリック入力
  指を置いたキーを離すまで固定し、上下左右のフリックで文字を選ぶ、一般的なフリック入力方式です。連打による文字送りにも対応しています。

・かな漢字変換
  オープンソースの変換エンジン Mozc を端末内に同梱し、完全にオフラインで動作させています。インターネット接続なしで、予測変換・かな漢字変換が使えます。

・誤フリックの校正候補
  フリックの押し間違いを想定した読みも裏で変換し、変換候補に校正案として並べます。例えば「てすのした」と打ち間違えても「テストした」が候補に出ます。

・変換候補の一覧表示
  候補欄の右端のボタンで、キーボード領域いっぱいに全候補をグリッド表示できます。

・ユーザー辞書
  よく使う単語を読みつきで登録すると、変換候補の先頭に優先して表示されます。

・クリップボード履歴
  Windows の「Win+V」のように、コピーした文字列を端末内に保存し、後からタップで貼り付けられます。パスワードマネージャー等の機微なコピーは自動的に除外されます。

・元に戻す / やり直し
  この IME で行った編集を Ctrl+Z 相当の操作で取り消せます。

・全選択 / 全選択してコピー
  ツールバーのボタンからワンタップで実行できます。

・片手モード / キーボード高さ調整
  キー配列全体を片側に寄せたり、高さをその場でドラッグ調整できます。

■ プライバシーについて

本アプリは INTERNET 権限を持たないため、通信そのものができません。入力した文字も、変換の学習データも、クリップボード履歴も、すべて端末内にのみ保存され、外部へ送信されることはありません。広告や解析 SDK も組み込んでいません。

詳しくはプライバシーポリシーをご覧ください。
```

## データセーフティ フォームの回答案

Play Console の「データセーフティ」セクションは Google 側の入力フォームなので、
以下の内容を見ながら手動で入力する。

| 質問 | 回答 |
| --- | --- |
| データを収集していますか？ | いいえ |
| データを共有していますか？ | いいえ |
| データは暗号化して送信されますか？ | 該当なし（送信自体を行わない） |
| データの削除をリクエストできますか？ | 該当なし（外部に送信・保存していないため） |

根拠: `AndroidManifest.xml` に `<uses-permission>` の宣言が一つも無く、
`INTERNET` 権限が無いためアプリはネットワーク通信を一切行えない
（コード上も `HttpURLConnection` 等の通信 API を呼んでいない）。
クリップボード履歴・ユーザー辞書・設定値はすべて端末内のアプリ専用ストレージ
（`getFilesDir()` / `SharedPreferences`）にのみ保存され、バックアップ以外で
端末外に出ることはない。

## 署名鍵について

- keystore/upload-keystore.jks をアップロード鍵として使う。
- Play Console で最初にアプリを作成する際、「Google が署名鍵を管理する
  (Play アプリ署名)」を選び、アップロード鍵としてこの keystore を登録する
  運用を推奨する（紛失時の被害を抑えられる）。
- パスワードは keystore/keystore.properties に平文で入っている。
  この2つのファイルは .gitignore 済みでリポジトリには含まれていない。
  **パスワードマネージャー等、Git 以外の安全な場所に必ず控えを取ること。**
  紛失すると同じアプリを二度と更新できなくなる。
